# Atmos runtime localization

Atmos provides an `I18n` QML singleton and a Node-testable JavaScript core. It loads the optional root-level `i18n.json` using Quickshell `FileView` (no `ratmos` request or subprocess). A missing or invalid catalog leaves English source strings available; a malformed replacement does not discard the last valid catalog.

## Catalog format

Use a flat map from locale tags to source-English strings and translated strings:

```json
{
  "es": {
    "Save": "Guardar",
    "Welcome, {name}": "Te damos la bienvenida, {name}"
  },
  "fr": {
    "Save": "Enregistrer"
  }
}
```

Locale keys should be lowercase language tags, optionally followed by a region (for example `pt-BR`). For compatibility with panel catalogs, each locale's value is a plain string map; there is no metadata or nested message schema. Do not add fabricated translations: untranslated entries safely display their English source.

## Runtime API

Import the services module and call:

```qml
import "../services" as Services

Text {
  text: Services.I18n.tr("Save")
}
```

The singleton exposes `locale`, `revision` and `rtl`. `revision` increments after successful catalog loads, so bindings may react to catalog replacement. `tr(source, args)` uses the English source as the lookup key and substitutes `{name}` placeholders from an optional object:

```qml
text: Services.I18n.tr("Welcome, {name}", { name: accountName })
```

Missing placeholder values are left unchanged. `trPlural(forms, count, args)` is available for explicit plural forms. Supply a `one` and `other` form at minimum; Arabic also selects `zero`, `two`, `few` and `many` where appropriate. The count is available as `{count}`. The basic categories support common English-style one/other languages; this intentionally is not a full CLDR plural engine.

## Locale selection

Resolution precedence is explicit `ATMOS_LANG`, `LANGUAGE`, `LC_ALL`, `LC_MESSAGES`, then the live system locale (`Omarchy.locale`), and finally session `LANG`. `LANGUAGE` accepts colon-separated preferences. Locale encoding suffixes and modifiers are stripped and underscores become hyphens. `C` and `POSIX` are ignored; no usable value defaults to `en`. Lookup tries the full locale, its base language, then English. The RTL flag is based on the resolved base language.

Atmos already watches `/etc/locale.conf` through the backend. Its snapshot updates `Omarchy.locale`, so a system-language change updates translation bindings without changing the process environment, restarting the desktop, polling, or writing a private language preference. Explicit overrides intentionally remain fixed; launch without `ATMOS_LANG` to follow the system.

Search indexes translated labels and descriptions alongside English aliases and uses a separate cache per locale. Results retain their source labels and IDs for navigation. Favorites and write feedback also keep source identities. Commands, enum values, usernames, paths, and detected device names remain literal.

The `prefs` IPC target exposes a read-only `language` diagnostic with the effective and system locales, loaded catalog names, and a translated sample. Select the actual running instance using the installed Quickshell CLI's IPC options; an installed source path alone is not proof that an instance is running.

## Tests

The shipped catalog covers every source key in Spanish, Portuguese, French, Italian, German, Dutch, Polish, Ukrainian, Russian, Turkish, Japanese, Korean, Simplified Chinese, and Arabic, plus English fallback. These translations are machine-authored and have not been approved by fluent human reviewers. Complete key coverage is a structural guarantee, not a claim of linguistic approval.

The current inventory is not an exhaustive guarantee that every runtime-generated sentence is localized. Some conditional and concatenated descriptions still fall back to English. Convert those messages to named-placeholder templates and extend every locale together rather than translating interpolated user data or changing stable identities.

`tests/i18n-catalog.test.js` checks that all fourteen requested locales exist, that their source-key sets match English exactly, and that values are nonempty strings with the same named-placeholder multiplicities.

Run `node tests/i18n.test.js` for locale selection, fallback, placeholders, RTL and plural checks. The pure functions are in `services/I18n.js` and can be loaded by Node without Qt or Quickshell.
