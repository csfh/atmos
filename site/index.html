Atmos

A Quickshell preferences window for Omarchy. It follows the active theme and writes through omarchy commands and Hyprland drop-ins.

Install Source

How it sits on the desktop

Sidebar hubs, a search field, and settings pages that match the running theme. Settings live in ~/.config.

This is an illustrative placeholder, not a product screenshot. Real shots are still pending (csfh/atmos#82).

Install

Copies the launcher, QML app, desktop file, and Hypr drop-in.

curl -fsSL https://raw.githubusercontent.com/csfh/atmos/stable/install.sh | bash

Then run atmos. From a clone, ./install.sh does the same thing.
